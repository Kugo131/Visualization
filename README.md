# Пульс покупок — интерактивный дашборд

Учебное ДЗ (Т3) по визуализации данных на **Vue 3 + D3.js**.

## Состав проекта

- `index.html` — структура интерфейса и Vue-шаблоны;
- `styles.css` — оформление и адаптивная вёрстка;
- `app.js` — фильтры, расчёты, SVG-график D3.js, интерактивность;
- `data.js` — данные из исходного CSV в формате JS (работают на GitHub Pages и при открытии HTML-файла напрямую);
- `items/` — извлечённые из предоставленного архива изображения товаров.

## Запуск

Можно открыть `index.html` в браузере при наличии доступа к интернету: Vue, D3 и шрифт загружаются из CDN. Надёжнее запустить локальный сервер в папке проекта: `python3 -m http.server 8000`, затем открыть `http://localhost:8000`.

## Размещение на GitHub Pages

1. Создать публичный репозиторий GitHub, например `orders-dashboard`.
2. Загрузить **всё содержимое** этой папки в корень репозитория (не забыть `items/` и `data.js`).
3. Открыть **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Выбрать `main` и `/ (root)`, нажать **Save**.
5. Страница будет доступна по адресу `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/orders-dashboard/` после публикации.

## Методика расчёта

- В расчётах используются **только доставленные** заказы (`status = доставлен`).
- **Число заказов** — количество уникальных `order_id` по каждому месяцу, а не количество строк товаров.
- **Сумма трат** — сумма `amount` (уже с учётом скидки), включая доставку и упаковку как часть оплаченного заказа.
- **Средняя скидка** — взвешенный процент экономии: `100 × Σ((price − price_discounted) × quantity) / Σ(price × quantity)`; не простое среднее по строкам.
- **Средний чек** — сумма трат / число уникальных заказов в текущем фильтре. При фильтрации по категории это траты на категорию / число заказов, в которых есть категория.
- **Рейтинг товаров** — сумма `quantity` (штук) либо сумма `amount` (рублей) по `item_name`, без строк категории «Услуги Груши» (доставка и упаковка).
- **Категории** — сумма `amount` по продуктовым категориям без «Услуги Груши»; услуги продолжают учитываться в общей сумме трат.
- Месячный график строится только для месяцев с записями после фильтрации. При выборе месяца сравнение по этому месяцу ведётся по всем выбранным годам.
- Фильтры года, месяца и категории применяются совместно ко всем показателям и графикам. Нажатие на название категории в блоке расходов тоже фильтрует дашборд.
- Изображения из архива автоматически сопоставлены с товарами по имени файла; если соответствие ненадёжно, используется нейтральный плейсхолдер.

## Технологии

- D3.js v7: группировка `d3.group`, расчёты `d3.sum`, линейный/точечный масштаб, оси, SVG, градиенты, наведение.
- Vue.js v3: реактивное состояние `ref`, вычисляемые наборы `computed`, слежение за изменениями `watch`, шаблонные компоненты и интерактивные фильтры.
- HTML5/CSS3: адаптивная вёрстка.

Исходные файлы — «Неделя 1_Визуализация_Датасет_Вариант B.csv» и `items.zip`.
